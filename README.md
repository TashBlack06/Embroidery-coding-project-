# Embroidery-coding-project-
A creative coding project that uses TurtleStitch to create an machine-embroidery design. The design includes a circle of stars, 4 different dog faces and a triangle pattern.

## General Info
- I wanted to recreate an embroidery design I created in highschool. The hand embroidery design took me a very long time to complete so I wanted to find a way to embroider a cute design in a much quicker way. 
- 4 different dog designs have been created, with their ears differing in shape.

 ## Technologies Used
- TurtleStitch 2.11.0
- Brother SE425 Computerised Embroidery Machine

##  Features
- Circle of stars - 12 stars form a circle shape.
- 4 dog faces who all have different ear designs. One dog has floppy curved ears (Bee Bee), one has short floppy ears (Digger), one has very short ears (Riely) and one has tall ears (Towbee).
- Expanding triangle design - trianlge expands 30 times

 ## Setup
  - No installation is needed to view the project.
  - Click the green flag to run the code
 To embroider the design, export the file to a dst and send the file to the machine. 

## Usage
- Open the project in TurtleStitch.
- Click the green flag to run the code
